## Finding

The batch runner's `docker run` lacked `--network none`. The now-retired
reconnaissance jobs also ran plugin code in networked containers. This
contradicted `docs/security.md` S2. All 24 reports already in the catalogue
were produced before the correction and therefore do not demonstrate the
promised no-egress property. The site and README disclose that limitation
without rewriting immutable reports.

## Changes

1. A networked container resolves an **exact** package version and downloads
   its dependency files with pnpm lockfile-only resolution and `pnpm fetch`.
   It runs no install scripts and rejects lockfiles mentioning git, file or
   link dependencies before fetching.
2. A fresh container receives that subject's private package store, sets pnpm
   offline mode and starts with `--network none`. Both containers are
   discarded; the per-subject store is deleted after the attempt.
3. An offline-cache miss is `inconclusive`, not an install failure. The report
   upload now includes only validated final reports and timings, not raw pnpm
   or execution logs.
4. The obsolete networked probe jobs were removed from `verify.yml`.
5. `stale` now compares the registry integrity for the **exact reported
   version** with the bytes recorded in the report. A mismatch is marked stale
   for investigation; missing metadata is unknown.

## Acceptance still required

The local host has no Docker executable. A maintainer-controlled CI run must
show that pnpm's store contains everything DSH's offline installer needs, that
the replay adapter runs without network, and that the resulting report passes
schema validation. Until then, do not publish a new execution report from this
path. The policy checker detects accidental removal of `--network none` and
`--ignore-scripts`, but static inspection is not a runtime acceptance test.

The registry freshness check ran locally without executing plugin code: 24
reports checked, 20 current, 4 stale, 0 unknown at the recorded timestamp in
`catalog/staleness.json`. No same-version integrity mismatch was observed.
